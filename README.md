### 📚 SkillNest — Learning Management System

A full-stack Learning Management System built with the MERN stack, covering the learning journey from authentication and course creation to enrollment and progress tracking.

**Highlights:**

* 🔐 JWT authentication with access & refresh tokens
* 👩‍🏫 Student and teacher roles
* 📚 Course, section & lesson management
* 💳 Course payment and enrollment flow
* ▶️ Course player with lesson progress tracking
* 📊 Student dashboard with learning statistics
* ☁️ Cloudinary-powered media uploads
* ⚡ React Query for server-state management

* 🔎 Course search, filtering and sorting
